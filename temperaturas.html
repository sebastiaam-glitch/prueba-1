¿Cómo se calcula la media?
Es la media aritmética de las ocho temperaturas actuales, con el mismo peso para cada localidad. Es una referencia orientativa: no es una media oficial de toda la superficie de Mallorca ni una media histórica. Los datos proceden de modelos meteorológicos y pueden diferir de una estación local.
